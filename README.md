# 坦克大战 (Battle City)

一个用纯原生 HTML + CSS + JavaScript（Canvas）实现的经典坦克大战小游戏，全部代码都在单文件 `index.html` 中，无需任何依赖，双击即可游玩。

## 玩法

- 每关消灭 **20 辆敌方坦克**即可过关，保护屏幕下方的**基地（老鹰）**不被摧毁
- 砖墙可被炮弹击穿；钢板只有满级火力才能摧毁；水塘无法通过；树丛可以藏身
- 4 种敌方坦克：普通 / 快速 / 强化 / 装甲（需 4 发炮弹）
- 关卡循环进行，第 4 关起敌人会越来越强，最高分保存在浏览器本地

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` 或 `方向键` | 移动 |
| `空格` 或 `J` | 射击（长按连发） |
| `P` | 暂停 |
| `M` | 静音 |
| `Enter` | 开始 / 重新开始 |

## 道具（击毁敌方坦克有概率掉落）

| 道具 | 效果 |
| --- | --- |
| ★ | 火力升级（满级可打穿钢板） |
| 盾 | 8 秒无敌护盾 |
| 命 | 生命 +1 |
| 爆 | 消灭场上所有敌人 |
| 停 | 冻结敌人 6 秒 |

## 运行方式

1. 直接双击 `index.html`，用浏览器打开即可
2. 或通过 [GitHub Pages](https://pages.github.com/) 在线游玩（在仓库 Settings → Pages 中选择 main 分支发布）

## 技术说明

- 纯原生实现：Canvas 渲染 + WebAudio 合成音效，无任何第三方库
- 地图、敌人 AI、碰撞检测、粒子特效均手写实现
- 坦克移动与经典版一致，沿网格吸附移动
